# Сравнение редакций

Локальное Streamlit-приложение для точного выделения различий в таблицах DOCX.

## Интерфейс

На странице остаются только основные действия:

1. **Сравнение редакций**
2. **Загрузить файл**
3. **Скачать готовый файл**

Обработка начинается автоматически после загрузки DOCX.

## Логика сравнения

- Отдельный первый столбец с номерами пунктов автоматически исключается.
- Левый договорный столбец считается единственной базой.
- Второй договорный столбец сравнивается только с базой.
- Если третий договорный столбец пустой, сравниваются только базовая редакция и второй договорный столбец.
- Если третий договорный столбец заполнен, он сравнивается только с базой.
- Второй и третий столбцы друг с другом не сравниваются.
- Каждая строка обрабатывается независимо.
- Отличающиеся слова выделяются целиком.
- Числа, даты, суммы, проценты, диапазоны и ссылки на пункты выделяются целиком.
- Различия только в пробелах, табуляции и переносах не выделяются.
- Отдельный отличающийся знак препинания выделяется отдельно.
- Пустые ячейки не изменяются.
- Служебные значения `Редакція Покупця`, `Редакція Постачальника`, `Редакція Замовника` и `Редакція Виконавця` в третьей версии исключаются без учёта регистра; допускается один заключительный знак `.`, `:`, `;`, `,` или тире.
- Используется только стандартная жёлтая подсветка текста.

Полный исходный промт находится в файле `COMPARISON_PROMPT.txt`.

## Запуск в Windows

Откройте командную строку в папке проекта и выполните:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Обычно приложение откроется по адресу:

```text
http://localhost:8501
```

## Тесты

```bash
python -m pytest -q
```

## Docker

```bash
docker build -t legal-docx-comparator .
docker run --rm -p 8501:8501 legal-docx-comparator
```

## Ограничения

Приложение принимает только редактируемые DOCX. Для PDF, сканов, изображений и снимков экрана нужен исходный редактируемый документ.

Сложные поля Word, Track Changes, гиперссылки, встроенные объекты и нестандартные объединения договорных колонок требуют обязательной ручной проверки результата. Приложение не заменяет юридическую экспертизу.
