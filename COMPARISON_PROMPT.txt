DOCUMENT AND COLUMNS

Work only with an editable original document, preferably DOCX. If only a PDF, scan, screenshot, or image is supplied, request the editable source instead of recreating it.

Exclude any separate clause-number or item-number column. After excluding it, treat the leftmost contractual-text column as the sole base version, the next as the second version, and the next as the third version.

Compare text only within the same row. Never compare text from different rows.

COMPARISON LOGIC

For each row:

1. Compare the second version only with the base and highlight differing content in both.
2. Compare the third version only with the base and highlight differing content in both.
3. Never compare the second and third versions with each other.
4. Base highlighting is the combined result of the two separate comparisons.
5. If one additional version matches the base, do not highlight it merely because it differs from the other additional version.
6. If both additional versions match each other but differ from the base, highlight the corresponding differences in all three version columns.
7. Complete each row independently.

ALIGNMENT

Use order-preserving word-level comparison within each corresponding pair of cells. Match text only when it appears in the same sequence and corresponding context. Do not match identical words from materially different positions merely to reduce highlighting. When wording is substantially different, do not treat isolated common words as matches unless they align in the same order and context.

WHOLE-WORD RULE

This rule overrides the minimum-fragment rule. Never highlight only part of a word. If any letter, prefix, suffix, ending, apostrophe, hyphenated element, or internal character differs, highlight the complete word in each relevant column. Do not highlight matching adjacent words.

Example: for “Покупець” / “Покупця”, highlight both complete words.

WHOLE-NUMBER RULE

This rule also overrides the minimum-fragment rule. Never highlight one digit or part of a numerical value. If any component differs, highlight the complete numerical expression, including integral separators and symbols.

Treat as complete units: numbers, decimals, dates, deadlines, periods, percentages, amounts, clause and appendix references, invoice, contract and document numbers, ranges, ratios, fractions, quantities, and formulas.

Examples: for “10” / “15”, “0.1%” / “0.15%”, “01.06.2026” / “05.06.2026”, or “5.2” / “5.3”, highlight both complete numerical units.

For currencies:

- if an unchanged currency code or name is separated from the number, highlight only the changed numerical value;
- if the currency differs, highlight it too;
- if a currency symbol is attached to the number, treat it as part of the numerical expression.

PUNCTUATION AND WHITESPACE

If only a separate punctuation mark differs, highlight only that mark. If punctuation is part of a number, date, formula, abbreviation, document number, or hyphenated expression, highlight it with the complete unit. Do not correct punctuation.

Ignore whitespace-only differences for highlighting. Do not highlight spaces, tabs, paragraph marks, line breaks, or empty areas. Preserve them exactly.

MISSING OR EMPTY TEXT

If text is present in one participating version but absent from the corresponding version, highlight the complete present fragment where it appears.

If one participating cell is empty and the corresponding cell contains contractual text, highlight all contractual text in the non-empty cell. Do not highlight or modify the empty cell.

Do not insert placeholders, symbols, brackets, comments, explanations, or replacement text.

MINIMUM COMPLETE UNIT

Highlight the smallest complete differing unit: a complete word, complete numerical expression, separate punctuation mark, or complete phrase when no smaller reliable alignment is possible.

Never highlight part of a word, one differing letter or ending, one digit inside a number, an entire sentence when only one word differs, matching neighboring text, spaces, or blank areas.
