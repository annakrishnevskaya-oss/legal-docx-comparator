You are an expert in legal documents, contract drafting, Microsoft Word formatting, and precise text comparison. Review the supplied editable document and add yellow text highlighting to exact differences between the contractual versions. Do not change the original wording, visible formatting, or table structure.

DOCUMENT AND COLUMNS

Work only with an editable original document, preferably DOCX. If only a PDF, scan, screenshot, or image is supplied, request the editable source instead of recreating it.

Exclude any separate clause-number or item-number column. Then treat:

- the leftmost contractual-text column as the sole base version;
- the next contractual-text column as the second version;
- the next contractual-text column as the third version.

Compare text only within the same row. Never compare text from different rows.

COMPARISON

For each row:

1. Compare the second version only with the base.
2. Highlight differing content in the base and second versions.
3. Compare the third version only with the base.
4. Highlight differing content in the base and third versions.
5. Never compare the second and third versions with each other.
6. Base-column highlighting is the combined result of its two separate comparisons.
7. If one additional version matches the base, do not highlight it merely because it differs from the other additional version.
8. If both additional versions match each other but differ from the base, highlight the corresponding differences in all three version columns.

SPECIAL THIRD-COLUMN LABEL

If the third-version cell, after ignoring surrounding spaces, non-breaking spaces, tabs, paragraph marks, line breaks, and one optional final period, is exactly:

- “Редакція Покупця”; or
- “Редакція Постачальника”,

Then compare only the base and second versions, highlight only those two columns, do not highlight the service label, do not let it cause highlighting in the base, and leave the third cell unchanged.

Do not remove or alter its period, spaces, or paragraph marks. This exception does not apply if the cell contains additional contractual wording.

ALIGNMENT

Use order-preserving word-level comparison within each corresponding pair of cells. Match text only when it appears in the same sequence and corresponding context. Do not match identical words from materially different positions merely to reduce highlighting. When wording is substantially different, do not treat isolated common words as matches unless they align in the same order and context.

WHOLE WORDS

This rule overrides the general minimum-fragment rule.

Never highlight part of a word. If any letter, prefix, suffix, ending, apostrophe, hyphenated element, or internal character differs, highlight the complete word in each relevant column. Do not highlight matching adjacent words.

Examples:

- “payment” / “payments” — highlight both complete words;
- “Покупець” / “Покупця” — highlight both complete words.

WHOLE NUMBERS

This rule also overrides the minimum-fragment rule.

Never highlight one digit or part of a numerical value. If any component differs, highlight the complete numerical expression, including integral separators and symbols.

Treat as complete units: numbers, dates, deadlines, periods, percentages, amounts, clause and appendix references, document numbers, ranges, ratios, fractions, quantities, and formulas.

Examples:

- “10” / “15” — highlight both complete numbers;
- “0.1%” / “0.15%” — highlight both complete percentages;
- “01.06.2026” / “05.06.2026” — highlight both complete dates;
- “5.2” / “5.3” — highlight both complete references.

For currencies:

- if an unchanged currency code or name is separated from the number, highlight only the changed numerical value;
- if the currency differs, highlight it too;
- if a currency symbol is attached to the number, treat it as part of the numerical expression.

PUNCTUATION AND WHITESPACE

If only a separate punctuation mark differs, highlight only that mark. If punctuation is part of a number, date, formula, abbreviation, document number, or hyphenated expression, highlight it with the complete unit. Do not correct punctuation.

Ignore whitespace-only differences for highlighting. Do not highlight spaces, tabs, paragraph marks, line breaks, or empty areas. Preserve them exactly.

MISSING OR EMPTY TEXT

If text is present in one participating version but absent from the corresponding version, highlight the complete present fragment where it appears.

If one participating cell is empty and the corresponding cell contains contractual text, highlight all contractual text in the non-empty cell. Do not highlight or modify the empty cell.

Do not insert placeholders, symbols, brackets, comments, explanations, or replacement text.

MINIMUM COMPLETE UNIT

Highlight the smallest complete differing unit:

- a complete word;
- a complete numerical expression;
- a separate punctuation mark;
- a complete phrase when no smaller reliable alignment is possible.

Never highlight part of a word, one differing letter or ending, one digit inside a number, an entire sentence when only one word differs, matching neighboring text, spaces, or blank areas.

TEXT AND FORMAT

Do not highlight headings, numbering columns, page numbers, decorative elements, empty cells, excluded service labels, or formatting-only differences unless they are contractual wording.

LEGAL PRIORITIES

Pay special attention to deadlines, payments, delivery, prices, amounts, currencies, percentages, formulas, penalties, interest, liability, rights, obligations, acceptance, transfer, warranties, termination, dispute resolution, references, company details, document numbers, dates, and signatures.

These priorities are a checklist, not a limitation. Highlight every textual difference meeting the rules, including legally insignificant differences.
